# 涨跌幅曲线按钮与售价输入框设计

## 目标

让“当前售价”输入框完整显示价格数字，同时让作物价格曲线按钮替换“涨跌幅度”数字左侧原有的方向字符箭头。

## 当前售价输入框

- 保留 `type="number"`、最小值和五位小数步长，售价仍可直接键入。
- 隐藏 Chromium、Safari 和 Firefox 提供的原生上下增减按钮。
- 撤销为原生按钮预留的 24px 右侧内边距，恢复左右普通内边距，让价格数字使用完整输入框宽度。
- 输入框聚焦后仍可使用键盘上下方向键微调数值。

## 涨跌幅度布局

- 移除涨跌百分比左侧原有的 `↑`、`↓` 和 `→` 字符箭头。
- 将现有曲线按钮移动到涨跌百分比左侧，直接占据原字符箭头的位置。
- 曲线按钮继续使用向上、向下或持平的折线图标，并保持红涨、绿跌、灰色持平的颜色规则，因此同时承担方向提示和打开曲线的操作入口。
- 涨跌百分比保持右对齐；单元格最终结构为“曲线按钮 + 百分比”，不再在百分比右侧重复显示按钮。

## 交互与可访问性

- 点击曲线按钮继续打开对应作物的价格曲线弹窗，沿用 `data-trend-seed` 事件委托。
- 按钮继续保留动态 `aria-label` 和 `title`，键盘用户可以通过 Tab 聚焦并按 Enter 或空格打开曲线。
- 售价输入框与曲线按钮互不嵌套，点击曲线按钮不会修改售价或触发输入框的 `change` 行为。

## 实现边界

- `renderPriceChangeRate` 只负责输出涨跌百分比及其颜色状态，不再生成字符箭头。
- `renderCropTrendTrigger` 的图标路径、颜色计算、标题和弹窗逻辑保持不变。
- `renderRow` 在 `price-change-cell` 内先输出曲线按钮，再输出涨跌百分比。
- CSS 简化 `price-delta` 的布局，删除字符箭头样式，并增加跨浏览器隐藏数字增减控件的规则。
- 不改变价格计算、历史数据、涨跌幅计算、表格列宽或曲线弹窗样式。

## 验证

- 更新 UI 契约测试，确认字符箭头已移除，曲线按钮只在涨跌百分比左侧出现一次。
- 测试售价输入框包含原生增减控件隐藏规则，并恢复普通右侧内边距。
- 运行完整 `npm test`、JavaScript 语法检查和差异检查。
- 在浏览器中验证五位小数完整显示、原生箭头消失、售价可输入、键盘方向键仍有效，并确认曲线按钮能打开正确作物的弹窗。

## 非目标

- 不提供新的鼠标点击式售价加减按钮。
- 不改变涨跌百分比的计算时间范围或显示精度。
