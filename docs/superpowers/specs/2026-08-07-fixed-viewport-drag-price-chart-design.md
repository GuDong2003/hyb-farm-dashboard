# 固定视口拖拽价格曲线设计

## 目标

恢复最初的固定宽度价格曲线：曲线只绘制当前选中时间段，不再把完整历史拉成超宽 SVG。横坐标补充北京时间日期，并允许用户在曲线区域直接拖拽或横向滑动查看更早、更新的数据，全程不显示横向滚动条。

## 时间范围语义

- `1h / 6h / 12h / 24h / 7d / 30d` 表示当前视口覆盖的精确时长。
- 打开弹窗或切换范围时，默认显示以最新历史时间为终点的区间。
- 历史总时长小于所选范围时，显示全部已有历史且不可继续拖动。
- `全部`始终在固定宽度曲线中显示完整历史，并关闭时间拖拽。
- 当前视口由一个 `visibleEnd` 时间锚点表示；它限制在“最早完整窗口终点”与“最新历史时间”之间。

## 交互

- 电脑鼠标：在曲线区域按住并拖动。向右拖查看更早数据，向左拖回更新数据。
- 触控板：横向滑动连续移动时间窗口。
- 手机和平板：在曲线区域左右滑动；纵向手势仍用于滚动页面。
- 拖动过程中使用 `requestAnimationFrame` 节流，实时重绘当前固定视口，不生成原生横向滚动容器。
- 鼠标样式使用 `grab / grabbing` 提示可拖动。
- 小于 4px 的指针移动仍视为点击，保留数据点点击和悬浮详情；超过阈值后才进入拖拽。
- 到达最早或最新边界时停止移动，不循环、不回弹。
- 隐藏数据点或异常值后保留当前 `visibleEnd`，不会跳回最新区间。

## 曲线渲染

- SVG 宽度始终等于曲线容器宽度，只把当前时间窗口内的数据映射到整张图。
- 纵坐标、首末价格、涨跌幅、红涨绿跌颜色、数据点数量和异常数量全部只根据当前窗口计算。
- 当前窗口不足两个有效历史点时显示数据不足，不显示误导性的 `0%`。
- `7d / 30d` 按北京时间为每个自然日绘制日期和竖向网格线；日期密集时沿用倾斜标签避免重叠。
- `1h / 6h / 12h / 24h` 显示当前窗口首末日期时间。
- `全部`根据完整历史跨度显示日期，不提供拖拽。
- 保留数据点悬浮时间/价格、隐藏数据点、隐藏异常值以及固定左侧等差纵轴。

## 数据与状态流

1. 完整历史点保留在现有历史数据结构中。
2. 范围选择和 `visibleEnd` 得到当前窗口的开始、结束时间。
3. 先截取窗口内数据，再应用异常值隐藏规则。
4. 使用处理后的窗口数据生成纵轴、折线、日期、统计和底部首末价格。
5. 拖拽或横向滑动只更新 `visibleEnd` 并重新执行步骤 2～4，不改变完整历史数据。

## 不采用的方案

- 不隐藏现有滚动条后继续使用超宽 SVG；这仍然保留了错误的完整历史长图逻辑。
- 不按整页离散翻动 7 天或 30 天；拖动应连续响应，而不是一次跳过完整区间。
- 不增加左右翻页按钮或额外时间导航控件。

## 验证

- 单元测试覆盖范围终点钳制、拖拽像素到时间偏移的换算，以及最早/最新边界。
- 浏览器验证鼠标拖拽、触控板横向滑动、移动端触摸、无横向滚动条和数据点点击阈值。
- 验证拖到不同涨跌区间时，纵轴、首末价格、涨跌幅和曲线颜色同步更新。
- 验证 `7d / 30d / 全部` 的日期布局以及隐藏数据点、异常值后的位置保持。
