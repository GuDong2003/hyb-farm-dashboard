# 可滚动可见时间窗价格曲线实现计划

> 本计划记录的超宽 SVG 滚动方案已停止使用；最终交互改为固定宽度 SVG，通过鼠标、触控板和触摸手势移动时间锚点。详见 `../specs/2026-08-07-fixed-viewport-drag-price-chart-design.md`。

**目标：** 完整历史作为横向时间轴，选择的 `1h / 6h / 12h / 24h / 7d / 30d` 表示一屏覆盖的时间长度；默认显示最新区间，向左滚动查看更早区间，`全部`一屏展示完整历史。

**实现方式：** 在纯时间工具中增加“完整历史宽度”和“滚动位置到可见时间段”的映射。曲线始终保留完整历史的横坐标；浏览器根据容器实际宽度设置时间轴宽度，并在滚动时按当前可见区间重新计算纵轴、折线纵向位置、首末价格、涨跌幅和趋势颜色。
