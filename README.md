# HYB Farm Dashboard

HYB Farm Dashboard 是一个面向 HYB 农场的作物收益、经验效率与价格历史分析工具。它通过用户脚本读取交易所实时价格，在浏览器内完成地块收益和农场经验计算，并可选择把公开价格快照提交到 Cloudflare D1。

- 在线地址：[https://hyb.gudong226.com](https://hyb.gudong226.com)
- 数据来源：[CDK](https://cdk.hybgzs.com/) 登录后的同源农场接口
- 部署架构：Cloudflare Workers Static Assets + D1

## 已实现功能

### 价格采集与同步

- 通过用户脚本获取 19 种普通及 VIP 作物的交易所售价。
- 支持打开页面自动导入、立即刷新和每小时自动刷新。
- 支持手动修改当前价格。
- 自动比较本地快照与云端默认快照的采集时间，优先采用较新的数据。
- 支持手动上传价格，或在导入后自动上传到云端校验池。
- 支持 `1h`、`6h`、`12h`、`24h`、`7d`、`30d` 涨跌幅区间；主页与单作物曲线统一按可见区间的首末历史价格计算，不足两个时间点时不显示误导性的零涨跌。
- 可在前后 1 小时涨幅达到 20% 时发送浏览器通知。

### 收益与经验分析

- 按 Lv1～Lv7 分别设置地块数量，总计最多 20 块。
- 各等级地块按对应产量和生长时间参与全地混合计算。
- 支持 `24h 理论轮转` 和 `16h 活跃估算` 两种模式。
- 展示并排序单次收益、单地小时收益、单地每天收益、全地每天收益。
- 展示并排序单次收获经验、单地每小时经验、全地每天经验。
- 汇总全地收益最优、全地经验/天最优和指定等级单地经验/小时最优作物。
- “单地指标等级”只切换表格中的单地指标，不影响全地混合计算。

### 农场等级与升级测算

- 输入当前总经验后自动计算当前农场等级。
- 显示距离下一级所需经验。
- 使用当前地块配置下全地理论经验最高的作物计算升级时间。
- 支持 Lv1～Lv100；Lv1 升 Lv2 需要 100 经验，此后每级需求乘以 1.5。

### 历史记录与价格曲线

- 本地导入快照保存在浏览器 IndexedDB。
- 已接受的云端价格快照保存在 Cloudflare D1。
- 历史页按采集时间倒序展示完整价格快照，可展开查看当次全部作物价格。
- 相同采集时间的本地与云端快照会合并显示，并支持分批加载更早记录。
- 在主页涨跌幅度列点击曲线图标，即可查看该作物的完整价格曲线；图标会同步显示红色上涨、绿色下跌或灰色持平状态。
- 单作物曲线支持 `1h`、`6h`、`12h`、`24h`、`7d`、`30d` 和全部历史范围，默认继承主页涨跌幅区间。
- 曲线始终保持固定宽度：有限范围表示当前显示的精确时长，默认停在最新数据；可在曲线区域使用鼠标拖拽、触控板横向滑动或移动端左右滑动查看更早和更新的数据，不显示横向滚动条。
- 横坐标按北京时间显示日期；`7d`、`30d` 和全部历史使用每日日期与竖向网格线，日期密集时自动倾斜。
- 拖动时间窗口时，纵坐标、首末价格、涨跌幅和整条曲线颜色实时按当前区间更新；红色表示上涨、绿色表示下跌、灰色表示持平。
- 曲线纵坐标根据当前可见价格范围自动缩放，使用五级等差刻度；默认保留两位小数，价格接近时自动提高精度，避免刻度重叠。
- 悬浮曲线数据点可查看完整时间与五位精度价格，移动端点击数据点也可显示。
- 曲线支持隐藏或重新显示全部数据点，数据密集时可只保留折线观察整体趋势。
- 单作物曲线可隐藏相邻涨跌超过 20% 所形成的异常区间，并随隐藏结果重新计算纵坐标。
- 隐藏状态会分别显示异常记录数量和隐藏的区间数据点数量。
- 支持历史数据 JSON 导出、导入和本地历史清空。

### 页面与使用体验

- 支持跟随系统、亮色和暗色主题。
- 表格各项指标可点击排序。
- 显示当前数据来源、最后导入时间和云端默认快照时间。
- 普通作物与 VIP 作物分别标识。

## 核心计算规则

### 地块等级

```text
毛产量 = round(基础产量 × (1 + (等级 - 1) / 3))
卖出产量 = 毛产量 - 1
生长时间 = 基础生长时间 × (1 - (等级 - 1) / 15)
```

每级地块都会提高收益和经验使用的产量，并缩短生长时间。

### 收益

```text
全地每天收益 =
Σ(该等级地块数 × 卖出产量 × 当前售价 × 每天轮转次数)
```

### 经验

```text
单块收获经验 = 作物基础经验 × 当前等级毛产量

全地每天经验 =
Σ(该等级地块数 × 作物基础经验 × 当前等级毛产量 × 每天轮转次数)
```

升级时间使用当前地块配置下经验/天最高作物的 `24h 理论轮转` 数值：

```text
升级时间 = 距下一级所需经验 ÷ 当前全地最高理论经验/天
```

## 数据流与隐私

默认情况下，农场布局、当前总经验、页面设置和本地历史只保存在当前浏览器。

```text
cdk.hybgzs.com
  -> 用户脚本在浏览器内读取同源价格接口
  -> 通过页面消息或 #snapshot URL 片段传给仪表盘
  -> 仪表盘保存到本地 IndexedDB
```

`#snapshot` URL 片段不会随 HTTP 请求发送到服务器。

只有用户点击“上传云端”或开启“导入后自动上传”时，作物价格和采集时间才会提交到 Worker。D1 保存的是公开价格快照、采集时间、提交状态元数据和用于防滥用的哈希指纹，不会主动上传农场布局、当前总经验、账号资料、库存或 Cookie。

更详细的说明见 [docs/privacy.md](docs/privacy.md)。

## Worker API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/default-prices` | 获取当前云端默认价格及趋势 |
| `POST` | `/api/price-submissions` | 校验并提交价格快照 |
| `GET` | `/api/price-history` | 获取云端价格历史与单作物曲线数据 |

## 本地开发

建议使用 Node.js 22 或更高版本。

```bash
npm install
npx wrangler d1 migrations apply PRICE_DB --local
npm run dev
```

本地开发服务器默认由 Wrangler 启动。

## 部署

首次部署或数据库结构更新时，先登录 Cloudflare 并应用 D1 migration：

```bash
npx wrangler login
npx wrangler d1 migrations apply hyb-farm-dashboard-db --remote
npm run deploy
```

只验证 Worker 和静态资源、不上传时：

```bash
npx wrangler deploy --dry-run
```

仓库中的 `.github/workflows/deploy.yml` 会在推送到 `main` 后自动部署。需要配置以下 GitHub Actions Secrets：

```text
CLOUDFLARE_API_TOKEN
CLOUDFLARE_ACCOUNT_ID
```

完整部署说明见 [docs/deployment.md](docs/deployment.md)。
